# ИИ-автоответчик для твоего Telegram-аккаунта

Бот работает от имени твоего личного аккаунта, а не через @BotFather. Он отвечает через нейросеть **только тем, кого ты добавил в список**, и для каждого человека держит свою цель. Остальные чаты он не трогает.

## Что умеет

- Отвечает только людям из списка, по `@username` или числовому ID.
- У каждого человека своя цель, например «довести до записи на консультацию».
- Перед ответом читает последние 30 сообщений переписки, поэтому помнит контекст.
- Отвечает не сразу, а как живой человек: пауза каждый раз разная (обычно от 20 секунд до 3 минут, иногда до 10 минут), в активной переписке быстрее. Потом читает, «печатает» с живой скоростью и иногда отвечает несколькими короткими сообщениями. Паузу можно настроить командой `/delay 20 180`.
- Если ты сам ответил человеку, бот не дублирует ответ. Молчать в чате после твоего сообщения можно включить: `/set quiet_min 10`. Ответить кому-то прямо сейчас: `/reply @username`.
- Если вопрос требует твоего решения, бот не отвечает, а присылает тебе уведомление в Избранное.
- Если прямо спросят «ты бот?», честно отвечает, что это ИИ-ассистент.

## Установка с телефона, без компьютера

1. Получи `api_id` и `api_hash` на https://my.telegram.org в разделе «API development tools».
2. На GitHub открой репозиторий → Settings → Secrets and variables → Actions → New repository secret и добавь:
   - `TG_API_ID`, `TG_API_HASH`
   - `TG_PHONE` — твой номер в формате `+79991234567`
   - `TG_2FA_PASSWORD` — облачный пароль Telegram, если он включён
   - ключ ChadGPT берётся из уже существующего секрета `CHAD_API_KEY`
3. Actions → Deploy to VPS → Run workflow, ветка `claude/bot-deployment-t9a0e5`, по очереди:
   - `ai-install` ставит автоответчик на сервер
   - `ai-login` присылает код в Telegram
   - `ai-code` с кодом в поле `code` выполняет вход и запускает бота
4. Потом `ai-logs` показывает логи, а `ai-stop` выключает бота.

Код из Telegram никому не пересылай внутри Telegram: если его переслать, Telegram заблокирует вход.

## Установка на компьютере

1. Получи `api_id` и `api_hash` на https://my.telegram.org в разделе «API development tools».
2. Установи зависимости и заполни настройки:

```bash
cd ai_responder
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впиши свои ключи
```

3. Первый запуск делай в терминале: Telegram пришлёт код входа, его нужно ввести вручную.

```bash
python responder.py
```

После входа появится файл `data/account.session`. Это ключ к твоему аккаунту: никому его не передавай и не заливай в Git (он уже в `.gitignore`).

## Управление

Пиши команды себе в **Избранное** (Saved Messages):

```
/persona Я делаю сайты под ключ. Цены от 50 000 ₽, срок 2–4 недели. Общаюсь на «ты», дружелюбно.
/add @ivan_petrov Узнать задачу и договориться о созвоне на этой неделе
/add @maria Напомнить про оплату второго этапа, вежливо
/list
/pause @maria 120
/off
```

Свой стиль задай командой `/style коротко, с маленькой буквы, без точек` и добавь несколько своих настоящих сообщений через `/example` (по одному на строку). Скобки-смайлики и эмодзи бот не ставит.

Полный список команд выдаёт `/help`. Сменить нейросеть можно командой `/model`, например `/model anthropic/claude-opus-5.5`.

Чем подробнее `/persona` (кто ты, услуги, цены, условия, тон), тем меньше бот выдумывает.

## Запуск на сервере (systemd)

```ini
# /etc/systemd/system/ai_responder.service
[Unit]
Description=Telegram AI responder
After=network.target

[Service]
WorkingDirectory=/root/bot/ai_responder
ExecStart=/root/bot/ai_responder/venv/bin/python responder.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now ai_responder
```

Перед этим войди в аккаунт один раз вручную на сервере (шаг 3), чтобы там появилась сессия.

## Нейросеть

- `AI_PROVIDER=chadgpt` использует тот же ChadGPT, что и бот расходов.
- `AI_PROVIDER=openai` подходит для любого OpenAI-совместимого API (OpenAI, OpenRouter и т. п.): укажи `AI_BASE_URL` и `AI_MODEL`.

## Риски

Автоматизация личного аккаунта разрешена через официальный API Telegram, но за спам аккаунт могут ограничить. Пиши только тем, кто сам тебе написал, и не делай рассылок незнакомым людям.
